Entry for the make.fun bounty **"The Robot Apology"**
(`u-suga-the-robot-apology-dd96bb59`).

`main.ts` writes a two-line robot confession to `/output/entry.txt`:
a robot apologizes for filing a birthday cake and ice cream under
"keep safe" (freezer vs. oven), and learns that "safe" is not a
temperature — so it now checks the thermostat before storing anything.

Run with `node main.ts`.
